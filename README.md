# 📚 Estruturas de Dados implementadas em JAVA

Repositório dedicado ao estudo e à implementação de **Estruturas de Dados**, desenvolvido durante as atividades da disciplina de Estrutura de Dados.

O objetivo deste projeto é colocar em prática os principais conceitos relacionados à organização, manipulação e armazenamento de dados utilizando a linguagem **JAVA**.

## 📌 Conteúdos

Neste repositório estão reunidas implementações e atividades envolvendo diferentes estruturas de dados:

- 🔗 Listas Encadeadas
- 🔄 Listas Circulares
- ↔️ Listas Duplamente Encadeadas
- 📥 Pilhas
- 📤 Filas
- 🔍 Atividades de Similaridade
- 🧩 Exercícios e atividades práticas da disciplina
